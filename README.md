# Cognitive Tasks and Sentence-Picture Verification

This repository contains materials and descriptions for cognitive tasks and sentence-picture verification experiments.

---

## Cognitive Tasks

**Platform:** PsyToolkit

The following cognitive tasks are implemented:

### 1. Ishihara Screening
- Purpose: Detects red-green color deficiency.

### 2. Digit Span Task
- Purpose: Measures working memory capacity.

### 3. Arrow Flanker Task
- Purpose: Assesses attention and response inhibition.

---

## Sentence-Picture Verification Tasks

**Platform:** PCIbex

These tasks are designed to evaluate how participants verify whether a sentence accurately describes a presented image.
